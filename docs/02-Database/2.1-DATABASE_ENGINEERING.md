# Database Engineering

## Purpose

The database is the source of truth for the PropVest platform. This section defines how data is modeled, stored, queried, migrated, optimized, and maintained throughout the lifecycle of the application.

## Scope

This section covers:

- Entity Relationship Diagrams (ERDs)
- Database naming conventions
- Primary and foreign key strategy
- UUID usage
- Migration strategy
- Indexing strategy
- Query optimization
- Transactions and ACID principles
- Isolation levels
- Locking and deadlock prevention
- Soft deletes
- Audit logging
- Data retention
- Backup and restore procedures
- Future partitioning strategy

## Principles

- Normalize first, denormalize only when justified.
- Every table has a clear ownership model.
- Every schema change is versioned through migrations.
- Financial operations must execute within transactions.
- Performance decisions are driven by measurement.
