# Background Jobs

## Purpose

Background jobs execute long-running or asynchronous tasks outside the HTTP request lifecycle.

## Scope

- Job queues
- Workers
- Retry policies
- Dead-letter queues
- Scheduled jobs
- Email processing
- Report generation
- Cleanup tasks

## Principles

- HTTP requests remain fast.
- Jobs are idempotent.
- Failed jobs are observable.
- Retries are controlled.
