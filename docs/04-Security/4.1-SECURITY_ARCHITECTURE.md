# Security Architecture

## Purpose

Security is a first-class engineering concern. Every layer of the PropVest backend must be designed to minimize risk while protecting users, financial assets, and sensitive information.

## Scope

This section includes:

- Threat modeling
- OWASP Top 10 mitigation
- Authentication security
- Authorization (RBAC)
- Password hashing
- JWT security
- Refresh token rotation
- API security
- Rate limiting
- File upload security
- Encryption
- Secrets management
- Audit logging
- Fraud prevention

## Principles

- Never trust client input.
- Validate everything.
- Least privilege by default.
- Encrypt sensitive data.
- Log security-relevant events.
- Fail securely.
