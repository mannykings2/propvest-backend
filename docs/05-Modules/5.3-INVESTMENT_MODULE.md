# Investment Module

## Purpose

The Investment Module manages the lifecycle of user investments and ownership in funded properties.

## Scope

- Investment creation
- Validation
- Ownership allocation
- Portfolio
- Returns
- Profit distribution
- Exit rules
- Investment history
- State transitions

## Principles

- Investments are transactional.
- Ownership calculations are deterministic.
- Every investment affects both wallet and property records.
- Historical records are immutable.
