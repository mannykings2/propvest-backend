# Property Module

## Purpose

The Property Module manages real estate assets listed on the platform from creation through approval, funding, and lifecycle management.

## Scope

- Property creation
- Approval workflow
- Property media
- Ownership
- Funding progress
- ROI configuration
- Documents
- Availability
- Status transitions

## Principles

- Properties are immutable after approval except through controlled workflows.
- Ownership history is preserved.
- Media is stored externally.
- Property status drives business behavior.
