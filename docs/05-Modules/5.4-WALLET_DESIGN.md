# Wallet Design

## Purpose

The wallet subsystem provides a secure ledger for storing user balances and processing financial transactions.

## Scope

- Wallet lifecycle
- Ledger design
- Balance calculations
- Deposits
- Withdrawals
- Transfers
- Holds
- Reserved balances
- Transaction history

## Principles

- Never update balances without recording a transaction.
- Balance is derived from ledger entries where practical.
- Financial consistency is more important than performance.
- Wallet operations are atomic.
